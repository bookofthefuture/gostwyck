Spyder Technical Service Manual

Revision 2.0

This technical service manual provides comprehensive documentation for the Gostwyck Spyder electric vehicle conversion, including component specifications, diagnostic procedures, maintenance schedules, and repair information.

Warning: This vehicle contains high-voltage electrical systems operating at up to 360V DC. Only qualified technicians with appropriate HV training should perform work on high-voltage components. Always follow lockout/tagout procedures.

Vehicle Overview

The Gostwyck Spyder is a ground-up electric conversion of a BMW Z3 roadster (E36/7 platform), built during 2020-2021 and progressively upgraded. The conversion features components from Mitsubishi Outlander PHEV and BMW hybrid donor vehicles, controlled via OpenInverter open-source software. The current v3.0 configuration features a customised Tribute Automotive Z300S body kit inspired by 1950s/60s sports cars.

Powertrain System

Motor - Version History

v1.0 - Front Motor/Generator (2020-2021)

The original build used the Mitsubishi Outlander PHEV front motor/generator unit. While this created a functional EV, performance was inadequate for the application.

v1.0 configuration - Outlander PHEV front motor/generator with original adapter plate design (2020-2021)

v1.0 Performance Issues

  • Poor Torque Curve: Motor designed primarily as a generator, not optimized for traction
  • Slow Acceleration: 0-60 times described as "pathetic" during June 2022 testing
  • Power Delivery: While kW output similar to rear motor, torque delivery unsuitable for vehicle propulsion
  • Decision: Led to complete motor upgrade in June 2022

v2.0+ - Rear Motor (June 2022 onwards)

The v2.0 upgrade replaced the front motor with the Mitsubishi Outlander PHEV rear traction motor, specifically designed for vehicle propulsion. This motor features larger magnets, better torque curve, and higher torque per amp.

Rear Motor Specifications (v2.0+)

  • Source: Mitsubishi Outlander PHEV rear traction motor
  • Type: 3-phase AC permanent magnet synchronous motor (PMSM)
  • Peak Power: ~60 kW (80 hp)
  • Peak Torque: ~195 Nm
  • Advantages over v1.0:
    • Significantly larger magnets
    • Superior torque curve for traction
    • More torque per amp drawn
    • Better acceleration characteristics
    • Improved efficiency for extended range
  • Mounting: Custom adapter plate to BMW E36/Z3 gearbox (lighter than v1.0 design)
  • Coupling: Custom coupler using Ford and BMW clutch centres

Known Issues - Motor Coupling

v1.0 Coupler Noise: Original coupler design produced excessive noise leading to MOT failure. Required complete teardown and rebuild with improved alignment. v2.0 incorporated lessons learned.

Inverter System

All versions of the Spyder use a Toyota Gen 3 Prius inverter paired with an OpenInverter control board. This combination has remained consistent throughout the build, providing reliable motor control for both the front motor/generator (v1.0) and rear traction motor (v2.0+).

Inverter System Components (All Versions)

  • Main Inverter: Toyota Gen 3 Prius power electronics unit (~£150)
  • Control Board: OpenInverter plugin board (£400)
  • Cooling: Liquid-cooled via vehicle coolant system
  • Power Rating: Suitable for motors up to ~80 kW peak
  • Features:
    • Field-oriented control (FOC)
    • Regenerative braking with adjustable levels
    • Configurable power curves and torque maps
    • CAN bus communication with BMS and VCU
    • WiFi-based web interface for parameter tuning
    • Real-time diagnostics and monitoring

OpenInverter Configuration

The OpenInverter board enables complete control over the Prius inverter, allowing it to drive various motor types. Parameters can be adjusted via WiFi connection for optimal performance with different motor configurations.

Transmission & Drivetrain

The Spyder retains the original BMW Z3 5-speed manual transmission and differential. The electric motor is coupled to the gearbox input shaft via a custom-fabricated adapter plate and coupler assembly. No clutch is used - the motor is direct-coupled to the input shaft.

Drivetrain Specifications

  • Gearbox: BMW Z3 5-speed manual (Getrag or ZF)
  • Final Drive: Original BMW differential (ratio varies by model)
  • Coupling Method: Direct coupling (no clutch)
  • Starting: Vehicle must be in neutral before energizing HV system
  • Gear Selection: Manual gear changes while driving, synchromesh operation

Battery System

Battery Pack Construction - Version History

v1.0 & v2.0 - BMW 330e Modules

The original battery pack configuration used 5 BMW 330e hybrid battery modules housed in a custom-built enclosure. This configuration provides approximately 7.6 kWh of usable capacity, achieving approximately 25 miles of real-world range.

330e Battery Pack Specifications (v1.0-v2.0)

  • Modules: 5× BMW 330e hybrid battery modules
  • Chemistry: Lithium-ion NMC (Nickel Manganese Cobalt)
  • Configuration: 80S (series cells)
  • Nominal Voltage: ~265V
  • Total Capacity: ~7.6 kWh
  • Enclosure: Custom-fabricated battery box (v2.0 lower mounted)
  • Mounting: Chassis-mounted for optimal weight distribution
  • Cost (2022): £800 for battery modules

v3.0 - BMW 530e Modules & Body Upgrade

The v3.0 upgrade brought two major changes: battery upgrade to 6 BMW 530e hybrid modules and a complete body swap to a customised Tribute Automotive Z300S kit. The 530e represents a more recent revision with higher energy density, providing increased range. The Z300S body kit transforms the Z3 into a 1950s/60s-inspired roadster reminiscent of classic Jaguar and Maserati sports cars.

530e Battery Pack Specifications (v3.0)

  • Modules: 6× BMW 530e hybrid battery modules (post-2020 revision)
  • Chemistry: Lithium-ion NMC (Nickel Manganese Cobalt)
  • Configuration: 96S (series cells)
  • Nominal Voltage: 355V (vs 265V/80S for 330e)
  • Total Capacity: 12 kWh
  • Advantages: Higher energy density, improved range, more recent cell technology (post-2020)
  • Enclosure: Same custom-fabricated battery box
  • Cost: £800 for battery modules

Body & Styling (v3.0)

  • Base Kit: Tribute Automotive Z300S
  • Cost: £2,650 inc. VAT (was £2,400 + VAT)
  • Customisation: Modified for electric vehicle packaging
  • Design: 1950s/60s British/Italian sports car styling
  • Influences: Jaguar and Maserati roadsters
  • Chassis: Retains original BMW Z3 structure
  • Material: GRP (fibreglass) body panels
  • Purpose: Completes the vintage sports car aesthetic

Battery Management System (BMS)

The battery pack is managed by a SimpBMS Spaceballs ESP32 system running customised code. The BMS monitors individual cell voltages, temperatures, and overall pack health to ensure safe operation and longevity.

BMS Specifications

  • Hardware: SimpBMS Spaceballs ESP32 board
  • Software: Custom-coded firmware
  • Processor: ESP32 microcontroller
  • Cost: £30
  • Configuration: Tailored for BMW 330e/530e modules

BMS Functions

  • Cell voltage monitoring and balancing
  • Temperature monitoring across all modules
  • State of charge (SOC) calculation
  • Overcurrent and overvoltage protection
  • Communication with main VCU via CAN bus
  • ESP32 enables WiFi connectivity for monitoring

High Voltage Junction Box - Version History

v1.0 - BMW 330e S-Box

The original build used the BMW 330e Safety Box (S-Box) as the high voltage junction box. This compact unit included integrated contactors, pre-charge relay, and current sensing, making it ideal for the initial lower-power build.

BMW S-Box Features (v1.0)

  • Compact size - fits inside battery box
  • Integrated contactors (smaller BMW units)
  • Pre-charge relay and resistor
  • Current sensing capability
  • CAN bus communication for voltage/current data

v2.0+ - Custom High Voltage Junction Box

The v2.0 motor upgrade required a complete redesign of the HVJB. The BMW S-Box contactors were insufficient for the higher-power rear motor, necessitating a custom solution with industrial-grade components.

Custom HVJB Components (v2.0+)

  • Main Contactors: 3× Gigavac GV242MAB contactors
    • High current rating for rear motor
    • Secondary contacts for position sensing
    • Negative contactor, primary contactor, charging isolation contactor
  • Pre-charge Resistor: Arcol high-power resistor
    • Safely charges inverter capacitors before full voltage connection
    • Critical safety component
  • Pre-charge Relay: Panasonic relay
    • Controls pre-charge resistor engagement
    • Engages before main contactors
  • Current Shunt: Isabellenhutte precision shunt
    • High-accuracy current sensing
    • Integrated power and CAN bus connections
    • Provides voltage and current data to VCU
  • Bus Bars: Custom copper bus bars (20mm × 2mm, >35mm² cross-section)
  • Control Connections: 16-way waterproof connector
  • Enclosure: ABS waterproof enclosure with steel mounting plate
  • HV Fusing: Main HV fuse protection

Reasons for Custom HVJB (v2.0+)

  • BMW S-Box contactors too small for rear motor power requirements
  • Needed additional capacity for second battery pack option
  • Required space for heater and charger connections
  • Allows reuse of OEM BMW battery pack connectors
  • Provides proper isolation between charging and driving modes
  • Industrial-grade Gigavac contactors for reliability

HVJB Operation Sequence

When the ignition key is turned:

  1. Negative contactor engages
  2. Pre-charge relay engages, connecting Arcol resistor
  3. Inverter capacitors charge slowly through resistor
  4. Once voltage equalizes, primary contactor engages
  5. Pre-charge relay disengages (resistor bypassed)
  6. System ready for full power operation
Warning: Never attempt to service the battery pack or HVJB without proper training. High voltage can cause serious injury or death. Always follow lockout/tagout procedures when working on HV systems. Multiple pre-charge resistors have been damaged due to wiring errors - extreme care must be taken during any service work.

Electrical System

High Voltage System

The high voltage (HV) system consists of the battery pack, BMW 330e HVJB (High Voltage Junction Box), inverter, motor, and associated cabling and safety systems. All HV cabling uses appropriate orange insulation and meets safety standards for high voltage automotive applications.

High Voltage Safety Systems

  • Main Contactors: Controlled via BMW 330e HVJB
  • Pre-charge Circuit: Ensures safe contactor closure
  • HV Interlock Loop: Safety disconnect system
  • Isolation Monitoring: Detects ground faults
  • Fusing: High voltage fuses protect major components

12V Auxiliary System

The 12V system powers vehicle accessories and control electronics. A DC-DC converter steps down from the HV battery to maintain the 12V auxiliary battery and power all low-voltage systems.

Auxiliary Systems Powered by 12V

  • Electric power steering pump
  • Electric vacuum pump (for brakes)
  • Electric coolant pump
  • Mitsubishi Outlander electric heater
  • Vehicle Control Unit (VCU)
  • BMS and monitoring systems
  • Lighting and accessories

Auxiliary Components

Power Steering

A Vauxhall Zafira electric power steering pump provides hydraulic assist without the need for an engine-driven pump. This pump operates on 12V and is controlled by the vehicle's power steering ECU.

Brake Vacuum

A Hella UP38 electric vacuum pump maintains brake booster vacuum, as there is no intake manifold vacuum from an ICE engine. This ensures normal brake pedal feel and assist force.

Hella UP38 Specifications

  • Model: Hella UP38
  • Voltage: 12V DC
  • Application: Brake booster vacuum generation
  • Cost: £30

Cooling System

The cooling system provides thermal management for the motor and inverter:

  • Coolant Pump: Bosch electric coolant pump (12V)
  • Radiator: Automotive radiator for heat rejection
  • Plumbing: Custom hoses connecting motor and inverter in series
  • Control: Temperature-based pump speed control

Cabin Heating

A Mitsubishi Outlander PHEV electric water heater provides cabin heating. The BMW heater controls have been modified with a potentiometer connected to an Arduino for temperature control.

Charging System

Onboard Charger

The Spyder uses a Mitsubishi Outlander PHEV onboard charger, providing 3.3 kW AC charging capability. This unit includes an integrated DC-DC converter for maintaining the 12V auxiliary battery. The charge port is sourced from the same donor vehicle and mounted in a convenient location on the bodywork.

Charger Components

  • Charger Unit: Mitsubishi Outlander PHEV (£120)
  • DC-DC Converter: Integrated within charger unit
  • Charge Port: Mitsubishi Outlander PHEV Type 2
  • Power Rating: 3.3 kW AC charging
  • DC-DC Output: 12V for auxiliary systems
  • Input: 230V AC single-phase
  • Connector: Type 2 (Mennekes) IEC 62196
Charging Specifications
AC Charging Power 3.3 kW
Charge Time (0-100%) ~2.5 hours @ 3.3 kW
Connector Type Type 2 (Mennekes)
Compatible Charging Home wallbox, public AC chargers

Charging Procedure

  1. Park vehicle and switch off all systems
  2. Open charge port cover
  3. Connect Type 2 charging cable
  4. Charging will begin automatically when cable is locked
  5. LED indicator on charge port shows charging status
  6. Charging completes automatically when battery is full
  7. Disconnect cable and close charge port cover

Charging Status Indicators

  • Solid Blue: Charging in progress
  • Flashing Blue: Charging scheduled/waiting
  • Green: Charge complete
  • Red/Flashing Red: Charging fault

Troubleshooting

Common Issues

Vehicle Won't Start

  • Check 12V battery voltage
  • Verify HV battery state of charge
  • Check main contactor operation
  • Inspect HV fuses

Reduced Power

  • Check for thermal limiting (motor or inverter overheating)
  • Verify battery state of charge
  • Check for error codes via web interface

Charging Issues

  • Verify power at charging point
  • Check charging cable connections
  • Inspect onboard charger status
  • Review BMS error logs
