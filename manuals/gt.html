GT Technical Service Manual

Revision 1.0

This technical service manual provides comprehensive documentation for the Gostwyck GT electric vehicle conversion, including component specifications, diagnostic procedures, maintenance schedules, and repair information.

Warning: This vehicle contains high-voltage electrical systems operating at up to 650V DC. Only qualified technicians with appropriate HV training should perform work on high-voltage components. Always follow lockout/tagout procedures.

Vehicle Overview

The Gostwyck GT is a ground-up electric conversion of a 1997 BMW Z3 roadster (E36/7 platform) imported from Japan in Montreal Blue. The conversion features a unique Lexus IS300h L210 transaxle system mounted in the transmission tunnel, controlled via OpenInverter ZombieVerter open-source software.

Powertrain System

Lexus IS300h L210 Transaxle

The GT uses the Lexus IS300h L210 transaxle, a compact hybrid eCVT (electronically controlled continuously variable transmission) unit. Unlike traditional use in a hybrid vehicle, this system is repurposed as a pure electric drive, with both motor-generators (MG1 and MG2) used for traction.

L210 Transaxle Specifications

  • Source: Lexus IS300h / GS300h / RC300h / Toyota Crown Hybrid
  • Type: Dual permanent magnet synchronous motor system
  • MG1 (Motor-Generator 1): Smaller motor, 2.6:1 ratio to output shaft
  • MG2 (Motor-Generator 2): Larger traction motor, 3.333:1 ratio to output shaft
  • Combined Peak Power: 105 kW (141 hp)
  • Combined Torque: 300 Nm
  • System Type: eCVT with planetary gear set
  • EV Conversion Method: ICE input shaft locked stationary (plate/bar)
  • Mounting: Transmission tunnel, replacing original BMW gearbox
  • Drive Configuration: Direct drive to BMW differential

L210 Operating Principle in GT Application

In the Gostwyck GT, the L210 transaxle is used differently from its OEM hybrid application:

  • Both MG1 and MG2 can be used for propulsion (not just MG2)
  • No internal combustion engine connection
  • eCVT functionality provides smooth power delivery
  • Planetary gear set allows variable drive ratios
  • System treated as "two big electric motors in a gearbox"

Inverter System

The L210 transaxle uses its matched Lexus IS300h inverter, controlled by the OpenInverter/EVBMW ZombieVerter open-source control system.

Inverter System Components

  • Main Inverter: Lexus IS300h G9200-30132 (Gen 3, matched to L210)
  • Controller: OpenInverter/EVBMW ZombieVerter
  • Dual Motor Control: Independent control of MG1 and MG2
  • OEM System Voltage: 650V DC (NiMH battery)
  • EV Conversion Voltage: 280-400V DC typical (boost stage bypassed)
  • Cooling: Integrated liquid cooling system
  • Communication: 140 byte MYH package protocol
  • Features:
    • Field-oriented control (FOC) for both motors
    • Regenerative braking via both motor-generators
    • Configurable power and torque curves
    • CAN bus communication
    • Open-source ZombieVerter firmware
    • GitHub-hosted IS300h inverter control board design

Transmission Tunnel Mounting

The L210 transaxle is mounted in the BMW Z3 transmission tunnel in place of the original gearbox. This requires custom mounting and fabrication work but provides a compact, integrated powertrain solution with the output shaft connecting directly to the BMW differential.

Mounting Advantages

  • Low center of gravity (maintains Z3 handling characteristics)
  • Compact packaging (transaxle + differential in original drivetrain location)
  • Retains original BMW rear subframe and differential
  • Balanced weight distribution

Battery System

Battery Pack Construction

The GT features a larger battery pack designed for extended range touring. The pack is housed in a custom-built enclosure and uses a modular design for serviceability.

[Diagram: Battery pack layout and mounting]

Battery Management System (BMS)

The BMS monitors individual cell voltages, temperatures, and overall pack health, with advanced algorithms for maximizing range and longevity.

Warning: Never attempt to service the battery pack without proper training. High voltage can cause serious injury or death.

Troubleshooting

Common Issues

Vehicle Won't Start

  • Check 12V battery voltage
  • Verify HV battery state of charge
  • Check main contactor operation
  • Inspect HV fuses

Reduced Power

  • Check for thermal limiting (motor or inverter overheating)
  • Verify battery state of charge
  • Check for error codes via web interface

Charging Issues

  • Verify power at charging point
  • Check charging cable connections
  • Inspect onboard charger status
  • Review BMS error logs
